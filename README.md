# סידור יארצייט של רב שלמה קרליבך זצוק״ל

אפליקציית ווב (PWA) עם תהלים ותפילת מנחה ליארצייט של רב שלמה קרליבך זצוק״ל, כולל קישורים להאזנה לשירי רבי שלמה ביוטיוב.
עובדת לגמרי בלי אינטרנט אחרי הפתיחה הראשונה (חוץ מהסרטונים עצמם).

## מבנה
- `index.html`, `app.css`, `app.js` – האפליקציה
- `content.json` – כל הטקסט, החלוקה לסעיפים והשירים (שם, סולם, מילים, קישור)
- `sw.js` – שמירה לשימוש בלי אינטרנט. **בכל שינוי בקבצים יש להעלות את `VERSION`** (למשל `siddur-v2`) כדי שהמכשירים יקבלו את העדכון.
- `fonts/` – גופן Frank Ruehl CLM מפרויקט Culmus (GPL עם חריגת גופנים, ראו `fonts/LICENSE-culmus.txt`)

## פרסום ב-GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
הכתובת תהיה `https://<user>.github.io/<repo>/`.

## עברית / אנגלית
הכפתור EN / עב בראש המסך מחליף את שפת הממשק. נוסח התפילות והתהלים נשאר תמיד בעברית.
- מחרוזות הממשק נמצאות ב-`STR` בראש `app.js`.
- ב-`content.json` לכל כותרת יש שדה מקביל באנגלית (`titleEn`, `introEn`, `groupEn`), להוראות בתוך התפילה יש `en`, ולמזמורי התהלים יש `trans` – תרגום JPS 1917 (נחלת הכלל) פסוק מול פסוק.

## עדכון קישור של שיר
ב-`content.json`, תחת `songs`, לכל שיר יש `yt` (מזהה הסרטון ביוטיוב), `key` (סולם) ו-`words`.
אחרי שינוי – להעלות את `VERSION` ב-`sw.js`.
