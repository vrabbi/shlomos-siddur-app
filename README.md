# סידור הילולת רבי שלמה קרליבך

אפליקציית ווב (PWA) עם תהלים ותפילת מנחה להילולת רבי שלמה קרליבך, כולל קישורים להאזנה לשירי רבי שלמה ביוטיוב.
עובדת לגמרי בלי אינטרנט אחרי הפתיחה הראשונה (חוץ מהסרטונים עצמם).

## מבנה
- `index.html`, `app.css`, `app.js` – האפליקציה
- `content.json` – כל הטקסט, החלוקה לסעיפים והשירים (שם, סולם, מילים, קישור)
- `sw.js` – שמירה לשימוש בלי אינטרנט. **בכל שינוי בקבצים יש להעלות את `VERSION`** (למשל `siddur-v2`) כדי שהמכשירים יקבלו את העדכון.
- `fonts/` – גופן Frank Ruehl CLM מפרויקט Culmus (GPL עם חריגת גופנים, ראו `fonts/LICENSE-culmus.txt`)

## פרסום ב-GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
הכתובת תהיה `https://<user>.github.io/<repo>/`.

## עדכון קישור של שיר
ב-`content.json`, תחת `songs`, לכל שיר יש `yt` (מזהה הסרטון ביוטיוב), `key` (סולם) ו-`words`.
אחרי שינוי – להעלות את `VERSION` ב-`sw.js`.
